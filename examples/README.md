# examples

Small, runnable examples of using assay.

- **quickstart.py** , run the six-agent desk as a library in a few lines and
  print the strongest edges. `python examples/quickstart.py`
- **sample_run.txt** , captured terminal output of `assay desk`, `assay scan`
  and `assay paper --settle`, so you can see the desk without running it.

For a machine-readable pipeline around the desk, see
[assay-signals](https://github.com/bl888m/assay-signals), which turns
`assay scan --json` into a CSV and a daily digest.
